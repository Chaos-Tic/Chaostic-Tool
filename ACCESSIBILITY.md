# Accessibility

We aim to make Chaostic-Tool usable through clear interaction and to improve accessibility as barriers are identified. We do not claim conformance to a particular accessibility standard.

## Current support and limitations

ChaosticTool offers terminal and desktop interfaces. The desktop has appearance and language preferences; available behavior varies by platform. See the [project documentation](README.md) and platform-specific guides for current support.

Compatibility with every assistive technology, platform and workflow has not been verified. Consult the project documentation for tested platforms and known limitations.

## Report a barrier

Please [open an issue](https://github.com/Chaos-Tic/Chaostic-Tool/issues/new/choose) and describe the task, the barrier, the application version, operating system, desktop environment and assistive technology if relevant. Avoid including personal or confidential information. Security vulnerabilities should be reported privately as described in [SECURITY.md](SECURITY.md).
