# Linux terminal edition

The maintained CLI guide lives on the
[`linux-cli` branch](https://github.com/Chaos-Tic/Chaostic-Tool/tree/linux-cli#readme).
It covers root installation profiles, Tor/proxychains, VPN guard, wordlists,
target-based results and the terminal menus.

```sh
git clone --branch linux-cli https://github.com/Chaos-Tic/Chaostic-Tool.git
cd Chaostic-Tool
sudo ./install.sh --profile minimal
sudo chaostictool
```

The root `install.sh` on Desktop branches also belongs to the CLI. To use the
graphical application, follow the [Windows guide](README_WINDOWS.md), the
[Linux GUI guide](https://github.com/Chaos-Tic/Chaostic-Tool/blob/desktop/linux-app/README_DESKTOP_LINUX.md)
or the [cross-system Desktop guide](docs/DESKTOP.md).
